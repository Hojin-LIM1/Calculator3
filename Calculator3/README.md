# Calculator3
두개의 양의 정수와 연산자를 입력 받아 사칙연산을 수행하는 계산기입니다!

연산과정은 아래와 같습니다.

1. 2개의 양의 정수와 연산자를 입력합니다.
2. 입력받은 연산자를 기반으로 사칙연산을 수행합니다.
   * 연산자에 +,-,*,/ 외에 문자를 입력하면 연산을 수행할 수 없습니다.
     - 위 연산자 중 하나를 꼭 입력해야 합니다.
   * 두번째 양의 정수에 0을 입력 후 "/"를 입력하면 오류가 발생합니다.
     - 위 경우 다시 처음부터 실행합니다.(정수와 연산자 입력)

3. 연산된 결과를 출력하고 연산된 결과는 별도의 컬렉션에 저장합니다.
4. 컬렉션을 확인 후 가장 오래된 연산결과를 삭제 할 수 있습니다.
     - Y : 연산결과 삭제
     - 아무키 : 연산결과 계속 저장
5. 연산 계속 여부를 확인 후 계산기를 종료하거나 연산을 지속할 수 있습니다.
     - exit : 연산종료
     - 아무키 : 연산 지속(처음으로 돌아갑니다.)
